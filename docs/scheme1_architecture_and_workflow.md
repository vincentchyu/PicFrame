# 📷 Scheme 1 小红书相机镜头卡片 (Gear & EXIF Info Card) 技术方案与交互流程规范

本文档详细记录 **Scheme 1（小红书相机镜头信息卡方案）** 的视觉系统、布局结构、动态色彩提取、器材素材匹配机制与端到端渲染流程。

---

## 1. 核心设计哲学与定位

Scheme 1 受到 Guizang social card workflow 启发，专为**小红书 / 朋友圈等社交媒体分享**定制：
- **核心定位**：将摄影照片包装为一张精致、克制、产品卡片质感的社交分享图，而不是杂乱的原始 EXIF 数据表格；
- **视觉层级**：
  - **第 0 层：摄影主画幅 (80%)**：保持原图高清晰度与真实比例（横图居中，竖图自适应）；
  - **第 1 层：柔和沉浸底色**：基于照片主色调自动生成柔和低饱和度的背景画布；
  - **第 2 层：器材产品拟物图**：展示真实的相机机身与镜头透明 PNG 剪影（如 Nikon Z6III / NIKKOR Z 24-120mm f4 S）；
  - **第 3 层：专业参数文字**：精确排版焦距、光圈、快门、ISO、相机型号、镜头型号、GPS 地理信息与版权标识。

---

## 2. 画布与排版布局结构 (Layout Architecture)

Scheme 1 采用固定卡片比例（3:4 / 4:3），内部划分为主图区、顶部悬浮胶囊区、底部器材胶囊区与版权微标：

```
+------------------------------------------------------------------------+
| 📍 [顶部左侧] GPS 经纬度与海拔胶囊标签 (若包含 GPS)                       |
|                                                                        |
|                                                                        |
|                          照片主画幅 (居中自适应)                         |
|                                                                        |
|                                                                        |
+------------------------------------------------------------------------+
|  [📷 相机拟物图]             [⚙️ 曝光参数组]             [🔍 镜头拟物图]  |
|  Nikon Z6III        24mm  f/4.0  1/125s  ISO 100    NIKKOR Z 24-120mm  |
+------------------------------------------------------------------------+
|                   © 2026 Vincent Chyu · All Rights Reserved            |
+------------------------------------------------------------------------+
```

### 2.1 `portrait` (默认竖版布局 · 3:4)
- **目标画布**：`1080 × 1440 px`（小红书黄金视觉比例）；
- **主图摆放**：照片自适应居中或偏上对齐，四周保持呼吸留白；
- **底部信息胶囊**：
  - 左侧：相机 PNG 剪影与型号标签；
  - 中间：核心曝光参数（焦距 · 光圈 · 快门 · ISO）；
  - 右侧：镜头 PNG 剪影与镜头型号标签；
- **顶部/底部浮动微标**：
  - 顶部左上角：GPS 经纬度与海拔胶囊标签（若照片含 GPS）；
  - 底部中央：版权年份与摄影师水印标识。

### 2.2 `landscape` (横图宽幅布局 · 4:3)
- **目标画布**：`1440 × 1080 px`；
- **适用场景**：当输入照片为竖图且用户指定横版展示时，自动扩展左右翼背景空间，实现沉浸式画幅呈现。

## 3. 核心机制与关键技术

### 3.1 柔和背景色自适应推导 (`_extract_soft_bg`)
- 对照片进行色调直方图聚类分析，提取主导色（Dominant Color）；
- 将色彩饱和度（Saturation）适度压低至画廊哑光质感，亮度（Lightness）微调至舒适底板范围，确保既呼应照片色彩，又绝不喧宾夺主。

### 3.2 器材产品图检索与映射体系
器材 PNG 素材按以下优先级自动回溯匹配：
1. 当前任务文件夹的 `assets/gear/`；
2. 方案内置目录 `assets/scheme1/gear/`（如 `Z6III.png`, `NIKKOR Z 24-120mm f4 S.png`）；
3. 找不到特定型号时，平滑降级至 `default-camera.png` 与 `default-lens.png`；
4. 型号别名匹配表维护在 `config/schemes/scheme1/gear_assets.json`。
